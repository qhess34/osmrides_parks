# osmrides_parks

Partie d'OSMrides : les parcs d'attractions d'OSMrides (Parc Astérix d'abord : Zeus, Trace du Hourra, OzIris, Goudurix) : données OSM des attractions, `SITE`, réglages `game.js`, pages de jeu et tutos des parcs.

Jeu de fan non officiel, données © contributeurs OpenStreetMap (ODbL).

## Éditeur

`docker compose up -d` puis http://127.0.0.1:8787/ (version de l'éditeur = `MOTEUR` de `jeu.html`). Sans Docker : `sh ../osmrides/tools/editeur.sh 0.5.0`.
